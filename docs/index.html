Hermes Pocket

Hermes Agent, in your pocket.

Hermes Pocket is a small Android app that hosts your own Hermes Agent web app. On the first launch it asks for your address — an IP and port on your network, or the public URL you use — and remembers it. Then you can talk to your agent, follow what it is doing, and answer approvals from your phone.

Download the APK

Direct APK · Android 8 or newer · about 2 MB

How sign-in works

  1. Enter your server: an IP and port, or your public URL.
  2. Sign in with the account that server already uses.
  3. Only that server is contacted — nothing is proxied or relayed.

Data

Hermes Pocket keeps one thing: the address you typed. No accounts, no logs, no analytics and no third-party calls — the app only renders the server you point it at, so the only data involved is the data that server already holds.
